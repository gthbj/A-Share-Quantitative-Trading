## 2. 背景与动机

### 问题 1：交易日历硬编码到 2024

`utils/calendar.py:20-51` 把 2020-2024 的长假写死，2025 年及以后的假期完全没有：
- 2025 春节、五一、国庆等假期回测时**会被当作正常交易日**
- 引擎按日历空跑（数据源返回空 bar）不会立即报错，但 nav 曲线会出现"假期跳空"伪影
- 项目所有者已表明长期跑回测到 2025+，必须解决

### 问题 2：Matplotlib 中文标签渲染为方框

`analytics/plotter.py` 中所有图表标题、轴标签为中文（如"累计收益率对比"），但 Matplotlib 默认字体 DejaVu Sans 不包含 CJK 字形，渲染时：
- 中文字符显示为 ☐ 方框
- 大量 `UserWarning: Glyph ... missing from font(s) DejaVu Sans.` 噪声

### 修复方向

1. **交易日历**：接入 `chinese_calendar` 或 `exchange_calendars`，自动获取至少到 2030 年的 A 股交易日。
2. **中文字体**：在 `Plotter.__init__` 中自动探测系统已安装的中文字体（macOS 用 PingFang SC / Heiti TC / STHeiti / Arial Unicode MS；Linux 用 Noto Sans CJK SC / WenQuanYi Zen Hei；Windows 用 Microsoft YaHei / SimHei），找到第一个可用的并设置为 `matplotlib.rcParams["font.sans-serif"]`。

不修复的后果：
- 日历：2025+ 回测假期混乱，nav 曲线包含"假期空 bar"，可能误判策略行为
- 字体：HTML 报告中所有图表中文乱码，可读性接近 0

## 5. 需求详情

### 5.1 功能目标

**A. 交易日历库化**

依赖选型对比：

| 库 | 优点 | 缺点 |
|---|---|---|
| `chinese_calendar` | 简单，专注法定假日 + 调休 | 需手动判断周六日 |
| `exchange_calendars` | 专门为交易所设计，含 XSHG (上交所) | 依赖较大，需 numpy/pandas |
| `pandas_market_calendars` | 类似上 | 类似上 |

**选 `chinese_calendar`**：依赖小（< 100KB），已覆盖到 2026 年（实测，每年初有版本更新），用 `chinese_calendar.is_workday()` 即可。

新 `TradingCalendar` 实现：

```python
import chinese_calendar

class TradingCalendar:
    @classmethod
    def is_trading_day(cls, date) -> bool:
        if isinstance(date, str):
            date = datetime.strptime(date, "%Y%m%d").date()
        # A 股交易日 = 工作日（chinese_calendar 已处理调休与法定假日）
        return chinese_calendar.is_workday(date)
    
    # 其他方法保持签名与行为不变
```

**fallback 兜底**：若 `chinese_calendar` 未安装或日期超出其覆盖范围（如 2027+），降级到"工作日且非周六日"逻辑 + WARNING。

**B. Matplotlib 中文字体探测**

在 `plotter.py` 模块加载时（matplotlib.use("Agg") 之后）：

```python
import matplotlib.font_manager as fm
import platform

def _setup_chinese_font() -> None:
    """探测并配置系统中可用的中文字体。"""
    system = platform.system()
    candidates = {
        "Darwin": ["PingFang SC", "Heiti TC", "STHeiti", "Arial Unicode MS"],
        "Linux": ["Noto Sans CJK SC", "WenQuanYi Zen Hei", "WenQuanYi Micro Hei"],
        "Windows": ["Microsoft YaHei", "SimHei", "SimSun"],
    }.get(system, [])
    
    available = {f.name for f in fm.fontManager.ttflist}
    for name in candidates:
        if name in available:
            plt.rcParams["font.sans-serif"] = [name, "DejaVu Sans"]
            plt.rcParams["axes.unicode_minus"] = False  # 避免负号渲染问题
            return
    # 探测失败时不抛错，仅 WARNING（环境无 CJK 字体）
    import warnings
    warnings.warn("未找到中文字体，图表中文可能渲染为方框")

_setup_chinese_font()
```

## 10. 备注

- **风险 1**：`chinese_calendar` 的版本覆盖范围有限，每年初需要 `pip install -U chinese-calendar` 才能拿到新一年数据。在 calendar.py 顶部加注释提醒。
- **风险 2**：CJK 字体探测在容器/CI 环境可能全部缺失。已增加 fallback WARNING。
- **风险 3**：硬编码假期与 chinese_calendar 实测可能有微差（如周末调休补班）。验收 9.2 需实际跑一次确认差异；如有差异需在 PR 中说明。
- 不存在 Lookahead Bias / 过拟合风险。
