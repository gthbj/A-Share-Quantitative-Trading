## 2. 背景与动机

项目已经经过多轮迭代，但 `README.md`、`ARCHITECTURE.md`、`engine/__init__.py` 与实际代码状态存在不一致：

1. **`README.md`** 仍写"项目结构"是 `strategy/double_ma.py`（单文件）、`data/processed/`（不存在的目录）、技术栈是 AKShare。实际已是策略实验包结构（`strategy/double_ma/{strategy.py, config.yaml, README.md, runs/}`），默认数据源是 MaxCompute，并已支持 `--preset` 用法。
2. **`engine/__init__.py`** 没有导出 `PaperTrader`，但 `ARCHITECTURE.md` §2.3 把它列为引擎层职责之一。外部用户按 `from engine import PaperTrader` 会失败。
3. **`ARCHITECTURE.md` §2.4** 把策略层写成 `double_ma.py / momentum.py` 等单文件结构，未反映策略实验包架构与 preset 机制。

不修复的后果：
- 新接手该项目的开发者会按 README 找 `strategy/double_ma.py`，找不到。
- `from engine import PaperTrader` 失败，提示对象不存在，影响二次开发体验。
- ARCHITECTURE.md 失去"权威文档"地位，新开发者无法据它快速上手。
