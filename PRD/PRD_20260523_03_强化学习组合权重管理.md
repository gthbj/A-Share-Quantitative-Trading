# A股强化学习（RL）组合权重管理策略 PRD

## 1. 背景与目标

不直接用 RL 预测价格（噪音太大），而是将 RL 用于**组合权重管理**：在已有多因子/多信号评分的基础上，由 RL 智能体决定最终的目标权重。日线级别多年数据提供了足够的样本量。

**目标**：
- 状态空间 = 因子暴露 + 市场环境 + 当前持仓
- 动作空间 = 目标权重调整（离散或连续）
- 奖励函数 = 夏普比率 + 最大回撤惩罚
- 面向中频，避免监督学习对未来函数处理的敏感

---

## 2. 策略原理

### 2.1 问题建模（MDP）

**状态 `s_t`**（每日收盘后观测）：
- 个股层面：动量因子、波动率因子、换手率因子、财务因子得分（来自 `ashare_mart.equity_features_1d`）
- 市场层面：沪深300收益率、市场成交额、涨跌停数量（来自 `ashare_mart.market_features_1d`）
- 持仓层面：当前各股票权重、未实现盈亏、持仓天数
- 状态维度：约 50~200 维

**动作 `a_t`**：
- **离散动作**（推荐小资金优先）：将目标权重映射为 5 档 `[-2, -1, 0, +1, +2]`，分别对应大幅减仓/小幅减仓/不变/小幅加仓/大幅加仓
- **连续动作**（进阶）：直接输出目标权重向量，通过 softmax 归一化

**奖励 `r_t`**（T+1 日收盘后计算）：
```
r_t = daily_return - lambda_1 * max_drawdown_penalty - lambda_2 * turnover_penalty
```
- `daily_return`：当日组合收益率
- `max_drawdown_penalty`：若当日净值创回撤新高，施加惩罚
- `turnover_penalty`：高换手惩罚，抑制频繁调仓

### 2.2 算法选择

| 算法 | 适用场景 | 推荐度 |
|------|---------|--------|
| **PPO**（Proximal Policy Optimization） | 连续/离散动作，样本效率较高，训练稳定 | ⭐ 首选 |
| **SAC**（Soft Actor-Critic） | 连续动作，最大熵探索 | 次选 |
| **DQN** | 离散动作，简单场景 | 入门可用 |

**框架**：`stable-baselines3`（Python，本地可运行，无需 GPU）

### 2.3 训练与回测分离

1. **训练阶段**（离线）：
   - 用 2015~2020 年历史数据训练 RL 智能体
   - 环境为 `gym.Env` 子类，每一步推进一个交易日
   - 每次 episode = 一年交易日，智能体在该年内调整权重

2. **回测阶段**（在线）：
   - 加载训练好的 RL 模型
   - 在 2021~2023 年数据上回测，不更新模型权重
   - 观察 OOS（样本外）表现，避免过拟合

### 2.4 与现有策略的衔接

RL 不做选股，只做**权重管理**。建议的输入信号来源：
- `MLStockPickerStrategy` 的 Top-K 打分
- `MultiFactorStrategy` 的多因子得分
- 用户自定义 alpha 信号

RL 智能体接收 alpha 信号 + 市场环境 + 当前持仓，输出最终目标权重。

### 4.2 核心类设计

```python
class AShareTradingEnv(gym.Env):
    """A股交易环境，兼容 stable-baselines3。"""

    def __init__(
        self,
        data_source: BaseDataSource,
        universe: List[str],
        start_date: str,
        end_date: str,
        initial_capital: float = 1_000_000,
        features_df: pd.DataFrame,   # equity_features_1d 宽表
        market_features_df: pd.DataFrame,
        alpha_scores: pd.DataFrame,  # 外部 alpha 信号
    ):
        ...

    def reset(self):
        self.current_date = self.start_date
        self.portfolio_value = self.initial_capital
        return self._get_observation()

    def step(self, action: np.ndarray):
        # action: 目标权重调整
        # 执行权重调整，推进到下一交易日
        # 计算 reward
        obs = self._get_observation()
        reward = self._calculate_reward()
        done = self.current_date >= self.end_date
        return obs, reward, done, {}


class RLPortfolioStrategy(BaseStrategy):
    """加载预训练 RL 模型，在回测中生成权重。"""

    def __init__(
        self,
        model_path: str,               # .zip 或 .pkl
        alpha_strategy: str,           # 外部 alpha 来源
        top_k: int = 20,
        rebalance_freq: int = 5,       # 每5个交易日调仓
    ):
        ...

    def initialize(self):
        self.model = PPO.load(self.model_path)

    def handle_data(self):
        obs = self._build_observation()
        action, _ = self.model.predict(obs, deterministic=True)
        target_weights = self._action_to_weights(action)
        self._rebalance(target_weights)
```

## 6. 风险评估

| 风险 | 说明 | 缓解 |
|------|------|------|
| 过拟合 | RL 在训练集上过度优化 | 严格划分 train/validation/test；监控 OOS 夏普 |
| 样本效率低 | 日级别样本量相对 RL 需求偏少 | 使用 PPO/SAC（样本效率较高）；或构造更多状态特征 |
| 动作空间爆炸 | 连续权重动作维度高 | 先离散化（5档）；或限制 universe 到 20~50 只 |
| 训练不稳定 | 奖励函数设计不当导致策略退化 | 奖励函数必须包含夏普+回撤惩罚；监控训练曲线 |
| 与回测引擎集成 | gym.Env 与现有 BaseStrategy 循环模型不同 | env.py 独立封装；strategy.py 只负责加载和推理 |

## 7. 验收标准

- [ ] `AShareTradingEnv` 兼容 `stable-baselines3` 的 `VecEnv`
- [ ] PPO 训练 50 万步后，validation 夏普 > 0.6
- [ ] OOS（2021~2023）夏普 > 0.4，最大回撤 < 20%
- [ ] 叠加到 ML 选股后，组合夏普比纯等权提升 > 5%
- [ ] 训练好的模型可保存为 `.zip`，回测时 `PPO.load()` 秒级加载
