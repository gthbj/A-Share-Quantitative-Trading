## 2. 背景与动机

PRD_20260524_12 交付的多 Horizon ML 策略当前是**一次训练永久使用**模式：

```
2017-01-01 ~ 2019-12-31 训练 → 同一组模型用于 2020-01-02 ~ 2025-04-30 全部回测
```

这在 5 年长回测中是不真实的——A 股 2020-2025 经历了疫情牛市、2022 持续熊市、2024 国庆反弹、
2024-Q4 增量资金，市场制度多次切换，**一组 2019 年训练的模型不可能稳定有效**。真实量化部署
是周期性重训。

同时 PRD_12 在 universe 选择上没有约束股票池，对应到真实账户可能：

- 普通账户没有北交所/科创板权限 → 选到的股票根本买不进
- ST/退市股价格异动 → 训练样本污染
- 账户配置应该决定 universe，不是策略写死

本需求解决以上两点：

1. **Walk-Forward Retraining**：滚动 3 年训练窗口 + 月度重训，全 5 年生成 ~64 套模型
2. **可交易股票限制**：账户级 `trading_permissions` 配置，全链路（训练 + 推理 + 回测）一致执行

不实现的后果：

- 不做走步重训：5 年回测严重高估策略稳定性，到产品化会发现"换月就失灵"
- 不做可交易限制：训练样本和回测信号包含账户无法交易的股票，所有结果失效

### 5.2 走步重训 (`walk_forward.py`)

CLI：

```bash
python -m strategy.ml_multi_horizon_picker.walk_forward \
    --config strategy/ml_multi_horizon_picker/walk_forward_config.yaml
```

执行流程（伪代码）：

```python
def main(config):
    # 1. 计算重训点列表
    retrain_dates = list_month_ends(
        config.walk_forward.start, config.walk_forward.end
    )

    # 2. 一次性加载训练特征数据（covers max_window 范围）
    features_df = bq_load_dws_features(...)
    kline_df = bq_load_kline(...)

    # 3. 加 sell-side 5 维风险特征
    features_df = enrich_sell_risk_features(features_df, kline_df)

    # 4. 应用 trading_permissions 过滤 universe
    features_df = filter_universe(features_df, permissions)

    # 5. 对每个 retrain_date 训一组模型
    for retrain_date in retrain_dates:
        # 5.1 取训练窗口（rolling）
        train_window = features_df[
            (retrain_date - rolling_window <= date) & (date <= retrain_date)
        ]
        # 5.2 算 buy labels（截面分位）
        labeled = build_buy_labels_cross_section(train_window, horizons=[1,5,10,20])
        # 5.3 算 sell label
        labeled = build_sell_label(labeled, lookforward=5, threshold=-0.05)
        # 5.4 训 5 模型
        models = train_all(labeled)
        # 5.5 保存到 models/walk_forward/{YYYYMMDD}/
        save_bundle(...)

    # 6. 写注册表
    write_registry("models/walk_forward/registry.json", retrain_dates)
```

### 5.3 模型注册表 (`model_registry.py`)

格式（JSON）：

```json
{
  "model_root": "models/walk_forward",
  "entries": [
    {"train_end_date": "20191231", "model_dir": "models/walk_forward/20191231"},
    {"train_end_date": "20200131", "model_dir": "models/walk_forward/20200131"},
    ...
  ]
}
```

查询接口：

```python
class ModelRegistry:
    def __init__(self, path: str): ...
    def find_for_date(self, current_date: str) -> Optional[str]:
        """返回 train_end_date < current_date 中最大的那个对应的 model_dir。
        如果都不早于 current_date，返回 None（早于走步起点，调用方应跳过）。
        月末收盘后训练出的模型只能从下一个交易日开始使用。
        """
```

## 9. 备注

### 9.1 Lookahead Bias 防护

| 风险点 | 防护 |
|---|---|
| 走步训练时用未来 N 天 label | label 函数自带保护：未来不可知时返回 NaN |
| 重训日选了"今日"的样本 | 训练数据截止 = retrain_date，且 horizon 天内 label 为 NaN 自动 dropna |
| 策略切换到新模型的边界 | find_for_date 返回 train_end_date ≤ current_date 的最新；不会偷看未来 |
| 截面分位计算 | 仅用当日截面，不跨日泄漏 |

### 9.2 性能估算

- BQ 一次性拉数据：~5 GB scan，HK$2 量级（含 dim_security join）
- 64 个重训点 × 5 模型 × ~30 秒/模型 = **~2.7 小时本地 CPU**
- 5 年回测执行：~30 分钟

总成本 < HK$5 + 一台 Mac 一夜。

### 9.3 v1 不做

- expanding window 重训（只做 rolling）
- 重训频率自定义（只做 month_end）
- 模型 ensemble（选最新的 1 套，不平均跨时点）
- 自动失败回退（如某月训练失败，回测当日直接跳过，不退到上月）
