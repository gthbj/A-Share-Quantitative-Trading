## 2. 问题描述

当前默认回测交易佣金为万分之 2.5，且单笔最低佣金 5 元。用户要求改为“万一免五”，即券商佣金费率为万分之 1（`0.0001`），并取消单笔 5 元最低佣金（`min_commission=0.0`）。

最小复现路径：

1. 打开 `config/backtest.yaml`。
2. 查看 `trading.commission_rate` 与 `trading.min_commission`。
3. 修改前：`commission_rate=0.00025`、`min_commission=5.0`。
4. 修改后：`commission_rate=0.0001`、`min_commission=0.0`。

## 3. 影响模块声明

| 模块 | 是否影响 | 说明 |
|---|---|---|
| `config` | 是 | 修改默认交易佣金参数。 |
| `engine` | 是 | `TradeEngine` 无显式参数时的默认佣金口径同步为万一免五。 |
| `CLI` | 是 | `run_backtest.py` 缺省 fallback 与配置默认保持一致。 |
| `analytics` | 间接影响 | 报告中的手续费结果会随新费率变化。 |
| `strategy` | 否 | 不修改买卖信号、持仓数量或风险预算。 |

本需求影响回测结果可复现性：同一份代码和配置下结果仍确定；但与旧费率相比，回测收益、交易费用和绩效指标会变化。

## 5. 需求详情

### 功能目标

1. 默认券商佣金改为 `0.0001`。
2. 默认最低佣金改为 `0.0`。
3. 保持印花税 `0.0005` 与过户费 `0.00001` 不变。
4. 保持滑点、撮合价格、成交量限制、T+1、涨跌停逻辑不变。

### 交互流程

用户运行回测 → CLI 读取 `config/backtest.yaml` → 构造 `TradeEngine` → 每笔成交按万一免五计算券商佣金 → 报告和交易明细输出更新后的手续费。

## 6. 配置变更

| 配置项 | 修改前 | 修改后 | 说明 |
|---|---:|---:|---|
| `trading.commission_rate` | `0.00025` | `0.0001` | 券商佣金从万 2.5 改为万 1。 |
| `trading.min_commission` | `5.0` | `0.0` | 取消单笔最低 5 元佣金。 |

## 7. 不可改动的红线区域

1. 不修改 `stamp_duty_rate` 和 `transfer_fee_rate`。
2. 不修改 `slippage.value`。
3. 不修改策略买入、卖出、regime、风险预算逻辑。
4. 不修改历史回测产物。
5. 不改变交易 CSV 字段格式。

## 9. 验收标准

用例 1：小额买入

- 输入：成交金额 `1000`
- 修改前佣金：`max(1000 * 0.00025, 5) = 5`
- 修改后佣金：`1000 * 0.0001 = 0.1`

用例 2：大额买入

- 输入：成交金额 `100000`
- 修改前佣金：`25`
- 修改后佣金：`10`

回测验证要求：

- 使用任意 preset 回测时，`trades.csv` 中 `commission` 应按 `amount * 0.0001` 计算，不再出现因最低 5 元导致的小额交易佣金放大。

## 10. 备注

“万一免五”只改变券商佣金，不等于免除印花税、过户费或滑点。A 股卖出印花税和交易冲击仍应保留，否则回测会过于乐观。
