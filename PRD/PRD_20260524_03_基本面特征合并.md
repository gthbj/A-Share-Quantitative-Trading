## 2. 背景与动机

当前已修复 `ashare.dwd_fact_financial_indicator`，并生成 `ashare.dws_equity_valuation_features`，该表只合并了财务指标表和行情表。下一步需要新增一版更完整的股票基本面特征层，把四类数据统一到日频：

- 财务指标表：`fact_financial_indicator`
- 利润表：`fact_income_statement`
- 资产负债表：`fact_balance_sheet`
- 行情表：`fact_equity_kline_1d`

最小复现/调研路径：

1. 查询现有利润表/资产负债表 DWD schema：
   ```sql
   SELECT * FROM `data-aquarium.ashare.dwd_fact_income_statement` LIMIT 1;
   SELECT * FROM `data-aquarium.ashare.dwd_fact_balance_sheet` LIMIT 1;
   ```
   当前现象：两张表是泛化 DWD，只有 `date`、`partition_month`、`equity_code`、`source_payload_json` 等字段，关键财务字段没有标准化。
2. 读取当前 GCS 源 Parquet schema：
   ```python
   import pyarrow.parquet as pq
   pq.ParquetFile("/tmp/fact_income_statement_sample.parquet").schema_arrow.names
   pq.ParquetFile("/tmp/fact_balance_sheet_sample.parquet").schema_arrow.names
   ```
   可观察到利润表真实字段包括 `营业总收入`、`营业利润`、`利润总额`、`净利润(不含少数股东损益)`、`研发费用`；资产负债表真实字段包括 `资产总计`、`负债合计`、`股东权益合计(不含少数股东权益)`、`货币资金`、`存货` 等。
3. 因此不能直接从当前泛化 DWD 的 `source_payload_json` 高质量抽取语义字段；需要像 `fact_financial_indicator` 一样，从当前正式 GCS Parquet 的真实中文 schema 抽取关键列，生成标准窄表，再合并到 DWS。

期望行为：

- 新增 `ashare.dws_equity_fundamental_features`，不覆盖已存在的 `ashare.dws_equity_valuation_features`。
- 新表以股票日行情为日频骨架，按公告日向后生效，合并财务指标、利润表、资产负债表。
- 不重新生成 `standardized_parquet_v2`，不删除或修改当前 GCS prefix。
- BigQuery 内部处理继续放在 `bigquery_pipeline/`，不回退到 `gcs_to_bigquery`。

## 5. 需求详情

### 功能目标

1. 新增 `bigquery_pipeline/fundamental.py`，负责：
   - 从当前 GCS Parquet 抽取利润表关键字段，生成 `ashare.dwd_fact_income_statement_core`。
   - 从当前 GCS Parquet 抽取资产负债表关键字段，生成 `ashare.dwd_fact_balance_sheet_core`。
   - 生成 `ashare.dws_equity_fundamental_features`。
   - 审计三张新表的行数、关键字段和非空指标。
2. 新增 DWD core 表字段：
   - `dwd_fact_income_statement_core`：
     `equity_code`、`announcement_date`、`report_period`、`partition_month`、`eps_basic`、`eps_diluted`、`total_revenue`、`operating_revenue`、`operating_cost`、`total_operating_cost`、`selling_expense`、`admin_expense`、`rd_expense`、`finance_expense`、`operating_profit`、`total_profit`、`net_profit`、`net_profit_parent`、`ebit`、`ebitda`。
   - `dwd_fact_balance_sheet_core`：
     `equity_code`、`announcement_date`、`report_period`、`partition_month`、`total_share`、`capital_reserve`、`retained_earnings`、`surplus_reserve`、`total_equity_parent`、`total_equity`、`monetary_fund`、`accounts_receivable`、`inventory`、`total_current_assets`、`fixed_assets`、`goodwill`、`total_assets`、`short_term_borrowing`、`accounts_payable`、`total_current_liabilities`、`long_term_borrowing`、`total_noncurrent_liabilities`、`total_liabilities`。
3. 新增 DWS 表 `dws_equity_fundamental_features`：
   - 行情字段：`equity_code`、`date`、`partition_month`、`close`、`volume`、`amount`。
   - 财务指标字段：EPS、BPS、ROE、毛利率、净利率、资产负债率、流动比率、速动比率。
   - 利润表字段：营业收入、营业成本、营业利润、净利润、归母净利润、研发费用、EBIT、EBITDA。
   - 资产负债表字段：总资产、总负债、股东权益、货币资金、应收、存货、商誉、总股本。
   - 派生字段：`pe_basic`、`pb`、`gross_margin_from_income`、`net_margin_from_income`、`debt_to_assets_from_balance`、`current_ratio_from_balance`、`asset_turnover_from_income_balance`、`market_cap`。

### 交互流程

```text
当前 GCS Parquet
  -> repair-fundamental-inputs
       -> dwd_fact_income_statement_core
       -> dwd_fact_balance_sheet_core
  -> transform-equity-fundamental-features
       -> dws_equity_fundamental_features
  -> audit-equity-fundamental-features
```

财务可见日期规则：

```text
source.announcement_date <= market.date
  -> 行情日只能使用已经公告的数据
  -> 每个来源独立按 announcement_date 生成有效区间
  -> 同一股票同一公告日多条记录按 report_period/source_hash 去重
```

## 10. 备注

- `dws_equity_fundamental_features` 是更完整的基本面研究特征表；`dws_equity_valuation_features` 保留为轻量估值表。
- `market_cap = close * total_share` 依赖源表 `期末总股本` 的单位，第一版保留字段供研究使用，策略正式使用前需再做口径校验。
- 利润表/资产负债表公告日不一定和财务指标表公告日完全一致，因此三个来源独立生成有效区间，避免强行按 `report_period` 合并造成未来函数。
