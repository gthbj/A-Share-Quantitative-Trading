# A股配对交易/统计套利策略 PRD

## 1. 背景与目标

A股同行业股票（如两只白酒、两只光伏组件）存在较强的协整关系。小资金可通过精选高相关性且流动性足够的标的对，在日线级别捕捉价差均值回归收益。

**目标**：
- 基于 `fact_board_component_1d` 筛选同行业股票对
- 使用 Engle-Granger 协整检验 + Kalman Filter 动态估计对冲比率
- 持仓周期 3~15 个交易日，符合中频定位
- 不依赖复杂算力，可在本地完成回测

---

## 2. 策略原理

### 2.1 配对筛选

1. **行业分组**：按 `fact_board_component_1d` 的 `board_code`（优先 `board_type='industry'`）分组
2. **相关性过滤**：计算同行业内股票对的日收益率 Pearson 相关系数，保留 > 0.8 的对
3. **协整检验**：对保留对做 Engle-Granger 两步法协整检验，ADF 检验 p-value < 0.05
4. **半衰期过滤**：估计价差序列的 OU 过程半衰期，保留 3~20 交易日的对

### 2.2 信号生成

**静态对冲比率**（经典 OLS）：
```
y = beta * x + alpha + residual
spread = y - beta * x
zscore = (spread - mean) / std
```

**动态对冲比率**（Kalman Filter，推荐）：
- 状态向量：`[beta, alpha]`，视为随机游走
- 观测方程：`y_t = beta_t * x_t + alpha_t + v_t`
- 实时更新对冲比率，避免beta漂移导致的对冲失效

**开仓条件**（以 z-score 为例）：
- 做多价差：`zscore > +2.0`（预期回归，做空y做多x）
- 做空价差：`zscore < -2.0`（预期回归，做多y做空x）

**平仓条件**：
- `|zscore| < 0.5` 平仓
- 或持仓超过最大持有期（如15天）强制平仓
- 或价差突破 3-sigma 止损（协整关系可能破裂）

### 2.3 资金管理

- 每对标的分配固定资金（如总资金的 5%~10%）
- 双边持仓，按对冲比率分配多空权重
- 由于 A 股不允许裸卖空，策略仅在回测框架内模拟多空；实盘需用融资融券或 ETF 替代

## 4. 实现方案

### 4.1 目录结构

```
strategy/
  pair_trading/
    __init__.py
    strategy.py          # PairTradingStrategy
    pair_selector.py     # 协整筛选、半衰期计算
    kalman.py            # KalmanFilter 动态对冲
    config.yaml          # 回测预设配置
    README.md
```

### 4.2 核心类设计

```python
class PairTradingStrategy(BaseStrategy):
    def __init__(
        self,
        board_code: str,               # 行业板块代码
        lookback: int = 60,            # 协整估计窗口
        entry_zscore: float = 2.0,     # 开仓阈值
        exit_zscore: float = 0.5,      # 平仓阈值
        stop_zscore: float = 3.5,      # 止损阈值
        max_holding_days: int = 15,    # 最大持仓天数
        use_kalman: bool = True,       # True=Kalman, False=OLS
        capital_per_pair: float = 0.1, # 每对资金占比
    ):
        ...

class PairSelector:
    def __init__(self, data_source: BaseDataSource):
        ...

    def select_pairs(
        self,
        board_code: str,
        start_date: str,
        end_date: str,
        corr_threshold: float = 0.8,
        adf_pvalue: float = 0.05,
        half_life_range: Tuple[int, int] = (3, 20),
    ) -> List[Pair]:
        """筛选符合条件的股票对。"""

class KalmanHedge:
    def __init__(self, delta: float = 1e-4, ve: float = 1e-3):
        """delta: 转移协方差；ve: 观测噪声。"""

    def update(self, x: float, y: float) -> Tuple[float, float]:
        """返回动态 beta, alpha。"""
```

### 4.3 回测流程

1. **initialize()**：
   - 调用 `PairSelector.select_pairs()` 筛选股票对（基于历史 in-sample 数据）
   - 为每对初始化 `KalmanHedge`（如启用）

2. **before_trading_start()**：
   - 更新每对的 Kalman Filter 状态
   - 计算当前 z-score

3. **handle_data()**：
   - 对每对检查开仓/平仓/止损条件
   - 生成多空订单（通过 `order()`）

4. **T+1 执行**：
   - 回测引擎以 `next_open` 撮合，避免未来函数

## 6. 风险评估

| 风险 | 说明 | 缓解措施 |
|------|------|---------|
| 协整关系破裂 | 基本面变化导致配对失效 | 3-sigma 止损 + 定期重新筛选（如每月） |
| 流动性不足 | 中小市值股票双边成交困难 | 过滤日均成交额 < 1亿 的标的 |
| 卖空限制 | A股无法裸卖空 | 回测模拟多空；实盘需融资融券或忽略此策略 |
| 参数过拟合 | lookback/zscore 过度调优 | 用 walk-forward 验证，避免全样本优化 |
