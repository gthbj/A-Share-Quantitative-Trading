# A股时序模型策略 PRD（HMM / Kalman Filter / GARCH）

## 1. 背景与目标

日线中频策略不必须依赖预测个股收益率。通过时序统计模型识别市场隐藏状态、动态估计因子暴露、或预测波动率进行仓位管理，同样能显著提升组合夏普比率。

**目标**：
- **HMM**：识别市场隐藏状态（趋势/震荡/反转），在不同状态下切换策略参数或空仓
- **Kalman Filter**：动态估计因子暴露或配对价差漂移
- **GARCH 族**：预测波动率，用于仓位管理（预测波动率上升时减仓）
- 面向中频（日线），计算量可控，本地即可完成

---

## 2. 策略原理

### 2.1 HMM（隐马尔可夫模型）市场状态识别

**状态定义**（3状态模型）：
- `Bull`：趋势向上，高动量，低波动
- `Bear`：趋势向下，负动量，高波动
- `Sideways`：震荡，动量接近0，中等波动

**观测变量**（每日计算）：
- 过去20日收益率均值（动量）
- 过去20日收益率标准差（波动率）
- 当日成交额 / 20日成交额均值（量能比）

**策略行为**：
| 当前状态 | 行为 |
|---------|------|
| Bull | 允许做多，仓位 80%~100% |
| Bear | 空仓或只做空头保护（如持有反向ETF），仓位 0%~20% |
| Sideways | 降低仓位至 40%~60%，或切换为均值回归策略 |

**实现**：使用 `hmmlearn.CategoricalHMM` 或 `GaussianHMM`，观测变量为高斯分布。

### 2.2 Kalman Filter 动态因子暴露

用于动态估计某只股票对基准指数（如沪深300）的 beta 暴露：

- 状态：`beta_t`（假设 beta 缓慢漂移，随机游走）
- 观测：`stock_return_t = beta_t * index_return_t + alpha_t + noise_t`

**用途**：
- 实时估计个股 beta，用于行业中性化或风险敞口控制
- 动态更新配对交易的对冲比率（已在配对交易 PRD 中使用）

### 2.3 GARCH 波动率择时

使用 `arch` 库的 `GARCH(p=1, q=1)` 模型，对基准指数（如 `000300.SH`）日收益率建模：

```python
from arch import arch_model

model = arch_model(returns, vol='Garch', p=1, q=1)
res = model.fit()
forecast = res.forecast(horizon=1)
next_day_vol = np.sqrt(forecast.variance.values[-1, 0])
```

**仓位管理规则**：
- 当预测波动率 > 过去60日波动率 80%分位数时，总仓位降至 50%
- 当预测波动率 < 过去60日波动率 20%分位数时，总仓位恢复 100%
- 可与任何选股策略叠加（如 MLStockPickerStrategy 叠加 GARCH 仓位管理）

### 4.2 核心类设计

```python
class HMMRegimeStrategy(BaseStrategy):
    """HMM 市场状态识别 + 策略参数切换。"""

    def __init__(
        self,
        index_code: str = "000300.SH",
        n_states: int = 3,
        lookback: int = 60,
        observation_window: int = 20,
        bull_position_pct: float = 1.0,
        bear_position_pct: float = 0.0,
        sideways_position_pct: float = 0.5,
    ):
        ...

    def initialize(self):
        # 用历史数据训练 HMM
        self.hmm = GaussianHMM(n_components=self.n_states, covariance_type="diag")
        self.hmm.fit(observations)

    def handle_data(self):
        state = self.hmm.predict(current_obs)[0]
        if state == self.bull_state:
            self.target_position_pct = self.bull_position_pct
        elif state == self.bear_state:
            self.target_position_pct = self.bear_position_pct
        else:
            self.target_position_pct = self.sideways_position_pct


class GARCHVolatilityTiming(BaseStrategy):
    """GARCH 波动率预测 + 仓位管理。可作为 wrapper 叠加到其他策略。"""

    def __init__(
        self,
        index_code: str = "000300.SH",
        lookback: int = 252,
        vol_window: int = 60,
        high_volile: float = 0.80,    # 高波动阈值分位数
        low_volile: float = 0.20,     # 低波动阈值分位数
        high_vol_position: float = 0.5,
        low_vol_position: float = 1.0,
    ):
        ...

    def handle_data(self):
        forecast_vol = self._forecast_volatility()
        hist_vol = self._historical_volatility(self.vol_window)
        if forecast_vol > np.percentile(hist_vol, self.high_volile * 100):
            self._scale_all_positions(self.high_vol_position)
        elif forecast_vol < np.percentile(hist_vol, self.low_volile * 100):
            self._scale_all_positions(self.low_vol_position)
```

## 6. 风险评估

| 风险 | 说明 | 缓解 |
|------|------|------|
| HMM 状态误判 | 状态切换有滞后 | 结合成交量确认，或用更短观测窗口 |
| GARCH 参数不稳定 | 局部最优，预测偏差 | 滚动重新估计，限制参数范围 |
| 波动率聚集失效 | 极端行情下 GARCH 低估尾部风险 | 引入 EGARCH 或 GJR-GARCH 捕捉杠杆效应 |
| 叠加复杂度 | wrapper 模式增加调试难度 | 先独立回测 GARCH 择时效果，再叠加 |

## 7. 验收标准

- [ ] HMM 能稳定识别出 2020~2023 年的牛/熊/震荡区间
- [ ] GARCH 预测波动率与实际波动率 rank correlation > 0.5
- [ ] 叠加 GARCH 仓位管理后，ML 选股策略夏普提升 > 10%
- [ ] Kalman beta 估计比滚动 OLS 更平滑，减少换手
- [ ] 支持 `--preset hmm_regime` 和 `--preset garch_vol_timing` 独立回测
