## 2. 问题描述

当前 BigQuery 中 `ashare.dwd_fact_financial_indicator` 已有 341,977 行，但核心字段不可用：`equity_code` 为 0 行非空，财务指标字段也没有被正确映射。问题根源不是 GCS 源文件缺数据，而是 ODS external table 用 `raw_col_001` 这类占位字段读取 Parquet；BigQuery external table 读取 Parquet 时按字段名匹配，源 Parquet 的真实字段名是中文列名，因此 `raw_col_*` 全部为 NULL，DWD 又把这些 NULL 打包成 `source_payload_json`，导致审计只看行数时误判通过。

最小复现步骤：

1. 使用 gcloud token 连接 BigQuery：
   ```bash
   export PATH=/Users/luna/.local/google-cloud-sdk/bin:$PATH
   export CLOUDSDK_PYTHON=/Users/luna/.local/share/uv/python/cpython-3.12.13-macos-aarch64-none/bin/python3.12
   export ASHARE_USE_GCLOUD_ACCESS_TOKEN=1
   ```
2. 查询 ODS external table：
   ```sql
   SELECT
     COUNT(*) AS row_count,
     COUNTIF(raw_col_001 IS NOT NULL) AS c001,
     COUNTIF(raw_col_002 IS NOT NULL) AS c002,
     COUNTIF(raw_col_050 IS NOT NULL) AS c050
   FROM `data-aquarium.ashare.ods_fact_financial_indicator`;
   ```
   当前现象：`row_count=341977`，抽样 `raw_col_*` 非空计数均为 0。
3. 查询 DWD table：
   ```sql
   SELECT
     COUNT(*) AS row_count,
     COUNTIF(equity_code IS NOT NULL) AS equity_code_rows,
     COUNTIF(source_payload_json IS NOT NULL) AS payload_rows
   FROM `data-aquarium.ashare.dwd_fact_financial_indicator`;
   ```
   当前现象：`row_count=341977`，`equity_code_rows=0`，`payload_rows=341977`。
4. 抽样读取 GCS 源 Parquet：
   ```python
   import pyarrow.parquet as pq
   table = pq.read_table("/tmp/fact_financial_indicator_sample.parquet")
   print(table.schema.names[:20])
   ```
   可观察到真实列名包括：`股票代码`、`公告日期`、`报告期`、`基本每股收益`、`稀释每股收益`、`每股净资产`、`销售毛利率`、`净资产收益率` 等，说明源数据本身存在。

期望行为：

- `fact_financial_indicator` 必须从当前 GCS Parquet 正确生成可用 DWD native table。
- DWD 审计必须校验关键字段非空，不能只校验行数。
- BigQuery 内部 DWD/DWS/ADS 处理逻辑必须从 `gcs_to_bigquery` 中拆出，避免 GCS 到 BigQuery 的 ODS 管道和 BigQuery 内部数仓加工混在一个文件里。
- 不重新生成 `standardized_parquet_v2`，只使用当前正式 GCS 数据：`gs://data-aquarium/a-share/standardized_parquet/`。

## 5. 需求详情

### 功能目标

1. 新建 `bigquery_pipeline/` 目录，承接 BigQuery 内部数据加工：
   - `dwd.py`：ODS external table 到 DWD native table 的通用转换与审计。
   - `financial.py`：`fact_financial_indicator` 的专门修复、加载、审计，以及估值特征生成。
   - `dws.py`：DWS 特征层转换与审计。
   - `ads.py`：ADS 信号层转换与审计。
   - `client.py` / `sql.py`：BigQuery/GCS 客户端、配置、表名、SQL helper。
   - `cli.py`：统一命令行入口。
2. `gcs_to_bigquery/` 仅保留 GCS manifest、ODS external table 创建、ODS audit、历史 staging/load 兼容命令；不再作为 DWD/DWS/ADS 的主入口。
3. 修复 `fact_financial_indicator`：
   - 直接读取当前 GCS prefix 下的原始 Parquet：`gs://data-aquarium/a-share/standardized_parquet/fact_financial_indicator/`。
   - 只抽取策略和估值需要的关键列，不复制 491 个原始字段到标准表。
   - 生成 `ashare.dwd_fact_financial_indicator` native table，标准字段包括：
     - `equity_code`
     - `announcement_date`
     - `report_period`
     - `partition_month`
     - `eps_basic`
     - `eps_diluted`
     - `revenue_per_share`
     - `bps`
     - `ocfps`
     - `gross_margin`
     - `net_margin`
     - `roe`
     - `roe_weighted`
     - `debt_to_assets`
     - `asset_turnover`
     - `current_ratio`
     - `quick_ratio`
     - `source_file`
     - `source_entry`
     - `source_hash`
     - `ingested_at`
4. 生成 DWS 估值特征表：
   - 新增 `ashare.dws_equity_valuation_features`。
   - 用 `announcement_date` 作为财报可见日期，不允许用 `report_period` 作为可见日期。
   - 与 `dwd_fact_equity_kline_1d` 的日线后复权行情按 `equity_code + date` 对齐。
   - 生成 `pe_basic = close / eps_basic`、`pb = close / bps`、`roe`、`gross_margin`、`net_margin`、`debt_to_assets` 等特征。
5. 加强审计：
   - `dwd_fact_financial_indicator` 审计必须校验 `equity_code`、`announcement_date`、`report_period` 非空。
   - `dws_equity_valuation_features` 审计必须校验行数、`pe_basic` 非空行数、`pb` 非空行数。
   - 若关键字段非空行数为 0，命令必须失败。

### 交互流程

开发/运维流程：

```text
当前 GCS Parquet
  -> gcs_to_bigquery 创建 ODS external table
  -> bigquery_pipeline 修复/生成 DWD native table
  -> bigquery_pipeline 生成 DWS 估值特征
  -> bigquery_pipeline 审计 DWD/DWS
  -> 策略/回测按需读取 DWD/DWS
```

财务指标可见日期规则：

```text
财报公告日 announcement_date <= 行情日期 date
  -> 当日及之后才可使用该财报
  -> 同一股票同一行情日取最近一个已公告财报
```

## 10. 备注

- `fact_financial_indicator` 源 Parquet 有约 491 列，存在大量中文、括号、百分号、斜杠等字段名。BigQuery external table 直接用占位字段名读取会失效，因此该表需要专门修复路径。
- ODS external table 仍可保留作为源层索引，但不能把当前 `ods_fact_financial_indicator` 当作可用业务数据来源。
- PE/PB 不是源表的直接标准字段，本需求通过财务指标和行情收盘价在 DWS 层派生，具体定义先采用 `pe_basic = close / eps_basic`、`pb = close / bps`。
- 财务指标公告日期是关键边界。所有基于财报的 DWS/ADS 特征都必须按公告日向后生效，不能按报告期提前生效。
