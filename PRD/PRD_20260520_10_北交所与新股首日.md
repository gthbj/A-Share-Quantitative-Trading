### 3.2 新股首日：前 5 个交易日无涨跌幅

**规则**（2023 全面注册制后统一）：

| 板块 | 上市首 5 个交易日 | 第 6 个交易日起 |
|---|---|---|
| 主板 / 创业板 / 科创板 / 北交所 | 无涨跌幅限制 | 恢复常规板块规则 |

**返回值约定**：`price_limit_pct` 在新股窗口内返回 `1.0`（±100%），撮合层用 `prev_close * (1+1.0) = 2*prev_close` 作为上限，几乎不会被拦截，等效"无限制"。这样**不需要在撮合层引入特殊分支**，保持涨跌停判定逻辑统一。

**判定函数**：

```python
def _is_within_first_n_trading_days(current: str, list_date: str, n: int) -> bool:
    """current 是否在 list_date 起前 n 个交易日内（含 list_date 当天）。"""
    # 用 TradingCalendar 数闭区间 [list_date, current] 的交易日数
    days = TradingCalendar.get_trading_days(list_date, current)
    return 1 <= len(days) <= n
```

### 3.3 `Order.list_date` + `TradeEngine.listing_dates` 双通道

策略可以走两条通道之一：

```python
# 通道 A：Order 显式带 list_date
context._orders.append(Order(code="688999.SH", ..., list_date="20240105"))

# 通道 B（推荐）：TradeEngine 预注入映射表
engine = TradeEngine()
engine.set_listing_dates({"688999.SH": "20240105", "832000.BJ": "20240108"})
```

`_try_fill` 取值优先级：

```python
list_date = order.list_date or self.listing_dates.get(order.code, "") or ""
```

不传 → `""` → `price_limit_pct` 走常规板块规则（向后兼容）。

### 3.4 `Order.to_dict` / `from_dict` 同步加 `list_date`

为了 PaperTrader 状态持久化时 list_date 不丢。

## 五、风险与边界

1. **`Order` 新增字段与 TBD-2 并发开发的冲突**：本期只加 `list_date` 字段。如 TBD-2 同时加 `expire_date` / `time_in_force`，merge 时 dataclass 字段顺序可能冲突，但语义独立，手动 resolve 即可。**`Context._orders` / `pop_orders` / 撮合主循环本期不改动**。
2. **chinese_calendar 覆盖范围**：`TradingCalendar.get_trading_days` 在 2027+ 会降级到 fallback（见 TBD-2/3 chinese_calendar）。新股首日判定不太可能跨年，但若 list_date 在覆盖范围外会有 1~2 天的误差。
3. **北交所数据源未配置**：本期只让代码层接受北交所代码与涨跌幅，数据源 `MaxComputeDataSource` 是否能拉到北交所 K 线**未验证**，由 `data_layer` 自行报错。
