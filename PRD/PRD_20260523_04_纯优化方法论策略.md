# A股纯优化方法论策略 PRD（风险平价 / MinVar / Black-Litterman）

## 1. 背景与目标

不预测价格，只通过组合优化配置权重。适合已经通过简单规则（如 ML 选股 Top-K、多因子打分）筛选出股票池后，用优化方法替代等权或市值加权。

**目标**：
- 实现风险平价（Risk Parity）、最小方差（Min Variance）、最大分散化（Max Diversification）
- Black-Litterman：结合先验观点（如"某因子近期有效"）调整配置
- 计算量可控，`cvxpy` 本地秒级求解

---

## 2. 策略原理

### 2.1 最小方差（Min Variance）

在预期收益率未知或不予考虑时，直接最小化组合方差：

```
min   w^T Σ w
s.t.  sum(w) = 1
      w >= 0   (不允许做空)
```

- `Σ`：股票池收益率协方差矩阵（用过去 60~120 日收益率估计）
- 优点：对预期收益率估计误差不敏感
- 缺点：倾向于集中配置低波动股票

### 2.2 风险平价（Risk Parity）

让每个资产对组合风险的贡献相等：

```
min   sum_i (w_i * (Σw)_i / (w^T Σ w) - 1/n)^2
s.t.  sum(w) = 1
      w >= 0
```

- 等价于 `w_i ∝ 1 / (Σw)_i` 的迭代解
- 优点：自然分散，不依赖预期收益
- 缺点：高杠杆倾向（但 A 股无杠杆约束，只需要权重和为1）

### 2.3 最大分散化（Max Diversification）

最大化分散化比率：

```
max   w^T σ / sqrt(w^T Σ w)
s.t.  sum(w) = 1
      w >= 0
```

- `σ`：各资产标准差向量
- 目标：在给定波动率下，尽可能分散到更多资产

### 2.4 Black-Litterman

结合市场均衡权重（先验）和投资者观点（后验）：

1. **先验**：市场均衡收益率 `Π = δ Σ w_mkt`（`w_mkt` 可为等权）
2. **观点矩阵 P**：例如 `P = [1, -1, 0, ...]` 表示"股票1跑赢股票2"
3. **观点收益率 Q**：如 `Q = [0.05]`
4. **后验收益率**：`μ_BL = [(τΣ)^-1 + P^T Ω^-1 P]^-1 * [(τΣ)^-1 Π + P^T Ω^-1 Q]`
5. **优化权重**：用 `μ_BL` 和 `Σ_BL` 做均值方差优化

**简化版**：
- 投资者观点来自策略层的 alpha 信号（如 ML 打分排名）
- 观点置信度与 alpha 信号的 IC 成正比

### 4.2 核心类设计

```python
class PortfolioOptimizer:
    """组合优化器，封装 cvxpy 求解。"""

    def __init__(self, method: str = "risk_parity"):
        self.method = method

    def optimize(
        self,
        cov_matrix: np.ndarray,
        expected_returns: Optional[np.ndarray] = None,
        risk_aversion: float = 1.0,
        max_weight: float = 0.20,      # 单只股票上限
        min_weight: float = 0.0,       # 下限
    ) -> np.ndarray:
        """返回优化后的权重向量。"""

    def risk_parity(self, cov_matrix: np.ndarray) -> np.ndarray:
        """风险平价。"""

    def min_variance(self, cov_matrix: np.ndarray) -> np.ndarray:
        """最小方差。"""

    def max_diversification(self, cov_matrix: np.ndarray) -> np.ndarray:
        """最大分散化。"""

    def black_litterman(
        self,
        cov_matrix: np.ndarray,
        prior_weights: np.ndarray,
        views: List[View],
        tau: float = 0.05,
    ) -> np.ndarray:
        """Black-Litterman。"""


class PortfolioOptStrategy(BaseStrategy):
    """组合优化策略。接收外部 alpha 信号，用优化方法分配权重。"""

    def __init__(
        self,
        alpha_strategy: str,           # 外部 alpha 来源
        method: str = "risk_parity",
        lookback: int = 60,            # 协方差估计窗口
        rebalance_freq: int = 5,       # 调仓频率
        max_weight: float = 0.20,
        risk_aversion: float = 1.0,
    ):
        ...

    def handle_data(self):
        # 1. 获取当前持仓和 alpha 信号
        alpha = self._get_alpha_scores()
        # 2. 计算协方差矩阵
        cov = self._estimate_covariance(self.lookback)
        # 3. 优化权重
        weights = self.optimizer.optimize(
            cov_matrix=cov,
            expected_returns=alpha,
            max_weight=self.max_weight,
        )
        # 4. 生成调仓订单
        self._rebalance(weights)
```

### 4.3 与现有策略的衔接

组合优化策略作为**权重分配层**，可叠加到任何选股策略：

```python
# 示例：ML 选股 + 风险平价权重
python run_backtest.py --preset ml_stock_picker \
  --opt-method risk_parity \
  --opt-max-weight 0.15
```

## 6. 风险评估

| 风险 | 说明 | 缓解 |
|------|------|------|
| 协方差矩阵估计误差 | 样本量小（60天）导致估计不稳定 | Ledoit-Wolf 压缩估计；或指数加权移动平均（EWMA） |
| 优化结果集中 | MinVar 倾向低波动大市值 | 加 `max_weight` 约束；或用 Risk Parity |
| 求解失败 | cvxpy 在某些边界条件下不可行 | 放宽约束；或使用 SCS/ECOS 替代默认求解器 |
| 与 T+1 执行冲突 | 优化权重按收盘价计算，次日开盘成交 | 策略层按 `next_open` 执行；优化时考虑滑点 |
