# PRD_20260524_09 回测产物 GCS 归档

## 1. 背景

当前 `run_backtest.py` 每次回测都会在本地生成独立输出目录，包含 HTML 报告、Markdown 摘要、收益图、回撤图、月度收益图和可选交易流水。随着策略实验增多，仅保存在本地不利于长期追踪，也容易在多 agent / 多 worktree 开发时遗漏重要结果。

## 2. 目标

每次回测成功生成本地产物后，自动将完整输出目录同步到 GCS，作为长期归档。

默认目标路径：

```text
gs://data-aquarium/a-share/backtest_runs/{strategy_key}/{run_label}/
```

其中：

- `strategy_key` 优先使用 `--preset`，否则使用策略类名。
- `run_label` 沿用当前本地输出目录名，例如 `20260524_150102_ml_smoke`。

## 3. 范围

包含：

- 新增回测输出归档配置。
- 上传本地输出目录内全部普通文件。
- 生成并一并上传 `gcs_archive_manifest.json`。
- 支持 `ASHARE_USE_GCLOUD_ACCESS_TOKEN=1`，复用当前 gcloud 登录身份。
- 支持 CLI 禁用归档，用于本地调试。

不包含：

- 把 GCS 产物做成公开网页。
- 改变回测撮合逻辑或指标算法。
- 将 BigQuery ADS 信号直接接入回测。

## 4. 配置

在 `config/backtest.yaml` 中新增：

```yaml
output:
  gcs_archive:
    enabled: true
    project_id: "data-aquarium"
    bucket: "data-aquarium"
    prefix: "a-share/backtest_runs"
    fail_on_error: true
```

`fail_on_error: true` 表示本地报告已生成但上传失败时，回测命令返回失败，避免误以为归档完成。

## 5. CLI

新增：

```bash
python run_backtest.py --preset ml_stock_picker --no-gcs-archive
python run_backtest.py --preset ml_stock_picker --gcs-archive-uri gs://data-aquarium/a-share/backtest_runs_tmp
```

## 6. 验收标准

1. 每次成功回测后，GCS 目标目录包含本地输出目录中的全部文件。
2. GCS 目标目录包含 `gcs_archive_manifest.json`，记录本地目录、远端 URI、策略、回测区间、初始资金、频率和上传文件清单。
3. 上传失败且 `fail_on_error: true` 时，命令返回非 0。
4. `--no-gcs-archive` 可跳过上传。
5. 单元测试覆盖 URI 解析、目标路径生成、manifest 生成和上传调用。
