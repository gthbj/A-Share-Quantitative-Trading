**日期**：2026-05-19  
**状态**：待实现

---

## 1. 背景

用户请求：查看 `cn_etf_kline_15min` 表是否包含沪深300指数基金 K 线，若有则用该数据运行双均线（`DoubleMAStrategy`）回测。

**表探查结果（2026-05-19 实测）**

| 字段 | 值 |
|------|----|
| 表名 | `cn_etf_kline_15min` |
| 分区键 | `year_month` STRING(YYYYMM) |
| 分区范围 | 200502 ～ 202512（共 251 个分区）|
| 代码格式 | **框架格式**（`510300.SH`），与 `cn_stock_kline_5min` 的 `sh510300` 格式不同 |
| trade_time 类型 | DATETIME |
| 全表扫描 | **禁止**，查询必须携带 `year_month` 分区条件 |

**沪深300 ETF 存在确认**

表中有大量沪深300相关 ETF，选取规模最大、流动性最好的标的用于回测：

| code | name | 数据起始月 |
|------|------|-----------|
| `510300.SH` | 沪深300ETF华泰柏瑞 | 2012-07 |
| `159919.SZ` | 沪深300ETF嘉实 | 待确认 |
| `510310.SH` | 沪深300ETF易方达 | 待确认 |

**本期仅对接 `510300.SH`（华泰柏瑞），理由**：成立最早（2012）、规模最大、流动性最佳，是市场的基准标的。

## 3. 技术设计

### 3.1 配置变更：`config/backtest.yaml`

```yaml
backtest:
  frequency: "15min"           # 改为 15min
  start_date: "20200101"       # 保持不变
  end_date: "20231231"         # 保持不变

data:
  maxcompute:
    tables:
      kline_etf_15min: "cn_etf_kline_15min"   # 新增 ETF 15min 表映射
      # kline_15min 仍为空（留给未来普通股票 15min 表）
```

**设计说明**：ETF 15min 表单独使用 `kline_etf_15min` 键，避免与未来的普通股票 `kline_15min` 混淆。

### 3.2 代码变更：`data_layer/maxcompute_source.py`

**`__init__` 文档字符串**：补充 `kline_etf_15min` 在 tables 参数说明里。

**`_fetch_minute_bars` 路由扩展**：

```
period="5min"   → kline_5min 表（代码格式：shXXXXXX，需双向映射）
period="15min"  → kline_etf_15min 表（代码格式：框架格式 XXXXXX.SH，无需映射）
其他 period     → NotImplementedError（原有逻辑不变）
```

**15min SQL 模板**（与 5min 相似，只差表名和代码格式处理）：

```sql
SELECT code, trade_time, open, high, low, close, volume, amount
FROM cn_etf_kline_15min
WHERE code = '510300.SH'
  AND year_month IN ('202001', '202002', ...)
  AND trade_time >= '2020-01-01 00:00:00'
  AND trade_time <= '2023-12-31 23:59:59'
ORDER BY trade_time
```

返回 DataFrame 列标准化：
- `date` = `trade_time` strftime `"%Y%m%d%H%M"`（12位，与 5min 一致）
- `code` 原样保留（已是框架格式，无需转换）

**`get_bars` 调整**：对 `period="15min"` 走 `_fetch_minute_bars` 路径（现有路由逻辑已覆盖，无需修改）。
