## 2. 背景与动机

### 问题 1：股票代码归一化逻辑双份维护

- `run_backtest.py:103-134` 有完整的 `_normalize_code()`：`510300` → `510300.SH`，按前缀推断交易所
- `data_layer/maxcompute_source.py:42-45` 同样定义了 `_SH_PREFIXES / _SZ_PREFIXES`，并有 `_to_exchange_code` / `_to_framework_code`
- 两份代码的行为略有差异：CLI 版本不识别前缀时抛错，MaxCompute 版本默认按 sh 处理 + warning

后果：未来扩展（如新增上交所 B 股 / 北交所 / 港股通）时需要改两处，且大概率改一处忘一处。

### 问题 2：基准 (benchmark) 加载使用回测频率

`engine/backtest.py:343-354`：

```python
def _load_benchmark(self, trading_days: List[Any]) -> pd.DataFrame:
    start = trading_days[0].strftime("%Y%m%d")
    end = trading_days[-1].strftime("%Y%m%d")
    try:
        df = self.data_source.get_bars(
            self.benchmark, start, end, period=self.frequency, adjust=None
        )
        return df
    except Exception:
        logger.warning("基准指数数据加载失败")
        return pd.DataFrame()
```

- 当回测频率为 `15min` 时，基准 `000300.SH`（沪深300指数）的 15min 行情**当前 MaxCompute 表中并不存在**（仅 ETF 15min 表有），调用会抛 `NotImplementedError`，被 try/except 静默吞掉
- 结果：所有 15min 回测的 benchmark 都为空 DataFrame，metrics 的 `benchmark_return / excess_return / beta / alpha / information_ratio` 全部为 0
- 用户在 HTML 报告和 summary.md 中看到"基准收益 +0.00% Alpha 0.00% Beta 0.00"会产生严重误解

### 修复方向

**基准始终用日线获取**（独立于回测频率），因为基准只用来做收益对比与 Beta/Alpha 计算，秒级精度毫无意义。

不修复的后果：
- 重复代码：未来扩展会出错
- 基准频率：所有分钟级回测的对标指标都失真，分析结论错误

### 5.1 功能目标

行为合并自现有两份实现：
- 不识别前缀时 **抛 ValueError**（采用 run_backtest 的更严格行为）
- 这与 maxcompute_source 当前的"默认 sh + warning"行为有变化，需要在 maxcompute_source 调用处显式 try/except 兼容

**B. `data_layer/maxcompute_source.py` 移除本地常量与方法，改为调用 utils.code**

**C. `run_backtest.py` 同上**

**D. `engine/backtest.py._load_benchmark` 强制 daily**

```python
def _load_benchmark(self, trading_days: List[Any]) -> pd.DataFrame:
    start = trading_days[0].strftime("%Y%m%d")
    end = trading_days[-1].strftime("%Y%m%d")
    try:
        # 基准始终用日线，避免分钟级表不存在的问题
        df = self.data_source.get_bars(
            self.benchmark, start, end, period="daily", adjust=None
        )
        return df
    except Exception as e:
        logger.warning(f"基准指数数据加载失败: {e}")
        return pd.DataFrame()
```

### 5.2 交互流程

1. 用户跑 `python run_backtest.py --preset double_ma --frequency 15min`
2. 引擎按 15min 加载策略行情，**但 benchmark 单独按 daily 加载**

## 10. 备注

- **风险**：metrics.Beta 计算中策略 returns 重采样到日线，如果回测区间内仅有少数交易日有数据，重采样后样本不足会导致 Beta 不可信。需要在 metrics 中加最小样本数校验（< 20 个日线点时不计算 Beta，输出 0）。
- **风险**：基准为日线后，HTML 报告中"累计收益曲线"的策略与基准时间轴不一致。Plotter 中需要将 benchmark 沿用日线索引（已有的 `bench.iloc[0]` 取首值做归一化的逻辑兼容），不必额外改。
- 不存在 Lookahead Bias，基准与策略均使用历史已知数据。
