# PRD_20260524_10 BQML 信号真实撮合回测

## 1. 背景

`ashare.bqml_ml_stock_picker_baseline` 已完成训练，`ashare.ads_signal_ml_stock_picker_bqml_1d` 已生成每日候选信号。但现有结果只是 BigQuery 中的粗略收益估算，没有经过 `BacktestEngine` / `TradeEngine` 的真实撮合、手续费、滑点、涨跌停、成交量限制、T+1 和持仓重叠约束。

用户当前资金规模为 10 万元，持有标的不应过多。第一版真实回测应限制在 1 到 3 只股票。

## 2. 目标

新增一个策略 preset：

```text
strategy/bqml_signal_picker/
```

该策略读取 BigQuery ADS 信号表，按每日 BQML 评分选择候选股，并交给现有回测引擎真实撮合。

第一版参数：

- 初始资金：100,000 元
- 回测区间：2025-01-02 ~ 2026-05-22
- 频率：daily
- 候选来源：`ashare.ads_signal_ml_stock_picker_bqml_1d`
- 每日候选池：`score_rank <= 10`
- 最大持仓数：3
- 最少目标持仓数：1
- 固定持有期：5 个交易日
- 总仓位上限：95%
- 单票目标市值：`总资产 * 95% / 目标持仓数`
- 已持有股票不重复加仓

## 3. 策略规则

每日 `handle_data`：

1. 对持仓年龄加 1。
2. 持有满 5 个交易日且 T+1 可卖时，提交卖出订单。
3. 从当天 ADS 信号取 `score_rank <= candidate_pool_size` 的候选股。
4. 跳过已持有、当日无行情、价格无效或买一手所需资金超过可用预算的股票。
5. 按评分顺序买入，直到持仓数达到 `max_positions` 或资金不足。

成交由现有引擎负责：

- T 日信号，T+1 开盘成交。
- 市价单叠加滑点。
- 佣金、印花税、过户费按 `config/backtest.yaml`。
- 涨停不可买、跌停不可卖。
- 单笔成交量不超过当日成交量 10%。
- 100 股整数手。

## 4. 非目标

- 不训练新的卖出模型。
- 不直接在 BigQuery 中模拟成交。
- 不改变现有 `TradeEngine` 撮合规则。
- 不把 ADS 信号接成通用数据源接口。

## 5. 验收标准

1. 可以运行：

```bash
python run_backtest.py --preset bqml_signal_picker
```

2. 回测报告显示策略为 `BQMLSignalPickerStrategy`。
3. `trades.csv` 存在且至少有一笔成交。
4. 最大持仓股票数不超过 3。
5. 输出目录自动归档到 GCS，并可同步到本地桌面 `output`。
