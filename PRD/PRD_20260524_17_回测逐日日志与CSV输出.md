## 2. 背景与动机

月度重训完整回测需要在 Cloud Run 上运行数小时。当前日志只输出模型切换、买卖和止损事件，无法实时看到：

- 当前已经跑到第几个交易日。
- 当前账户总资产、收益、回撤和现金状态。
- 与沪深300、上证50、中证500、中证1000、创业板指的阶段对比。
- 每日持仓、候选信号和当日交易明细。

不实现的后果：用户只能等待整段回测结束后查看 `summary.md`、`nav.csv` 和 `trades.csv`，无法判断中途表现、进度和异常风险。

## 5. 需求详情

### 5.1 功能目标

1. Cloud Run 回测过程中每天输出结构化日志：
   - `DAY_SUMMARY`
   - `DAY_POSITIONS`
   - `DAY_CANDIDATES`
2. 回测结束后输出以下 CSV，随报告一起归档到 GCS：
   - `daily_log.csv`
   - `daily_positions.csv`
   - `daily_candidates.csv`
3. 每个 CSV 第一行为中文表头，第二行为英文表头。
4. CSV 写入只发生在容器本地输出目录，GCS 上传仍由现有归档工具在回测结束后一次性完成。
5. 为满足实时查看需求，本地监控从 Cloud Logging 读取 `DAY_*` 行，并把 live CSV 重写到 `/Users/luna/Desktop/output/<run>/`。

### 5.2 交互流程

用户启动 Cloud Run 回测 → 引擎逐交易日推进 → 每日收盘后计算 NAV/收益/回撤/持仓/候选 → 输出结构化日志 → 回测结束后写出 CSV → 现有 GCS 归档工具上传全部产物。

### 5.3 日志字段

`DAY_SUMMARY` 至少包含：

- 日期、交易日序号、总交易日数、完成进度。
- NAV、累计收益、当日收益、最大回撤。
- 现金、持仓市值、现金占比、持仓数量。
- 当日买入/卖出笔数、当日费用。
- 当前模型训练截止日、模型路径、regime、目标持仓数。
- 沪深300、上证50、中证500、中证1000、创业板指收益和最大回撤。
- 相对沪深300超额收益。

`DAY_POSITIONS` 输出当前持仓摘要。

`DAY_CANDIDATES` 输出当日 Top 候选摘要。

## 6. 配置变更

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `--daily-diagnostics` | CLI flag | false | 启用逐日实时日志和 CSV 输出 |
| `--daily-candidate-top-n` | CLI int | 10 | 每日候选 CSV/日志输出 Top N |
| `scripts/sync_cloud_run_daily_logs.py --output-dir` | CLI path | 无 | 本地 live CSV 输出目录 |

Cloud Run 完整回测脚本默认传入 `--daily-diagnostics --daily-candidate-top-n 10`。

## 7. 不可改动的红线区域

- 不改变 `TradeEngine` 撮合规则。
- 不改变 T+1、滑点、佣金、印花税、过户费、涨跌停逻辑。
- 不改变策略买卖规则、模型预测和排序逻辑。
- 不每天上传 GCS，避免 API 小文件开销拖慢回测。
- 不把 `config/secrets.yaml` 写入镜像。

## 9. 验收标准

1. 单元测试：
   - 输入一组 DailyRecord，调用 CSV 写出工具。
   - 预期 CSV 第一行为中文表头，第二行为英文表头，第三行开始为数据。
2. 回测 smoke：
   - 命令：`python run_backtest.py --preset ml_multi_horizon_picker --start 20200102 --end 20200228 --daily-diagnostics --no-gcs-archive`
   - 预期输出目录包含 `daily_log.csv`、`daily_positions.csv`、`daily_candidates.csv`。
3. Cloud Run：
   - 日志中能看到 `DAY_SUMMARY`。
   - GCS 归档目录中能看到三个 CSV。
   - 本地监控可在 `/Users/luna/Desktop/output/<run>/` 生成 `daily_log_live.csv`、`daily_positions_live.csv`、`daily_candidates_live.csv`。
4. 回测复现性：
   - 启用诊断前后，在相同数据和模型下，交易和 NAV 不应因日志/CSV 输出而改变。

## 10. 备注

每日日志和 CSV 会增加少量 CPU 与本地磁盘写入，但不做每日 GCS 上传，因此相对 500 股票逐日评分的总耗时影响应很小。
